# 星火纪元（SparkAge）游戏设计

> 目标：一局 10~20 分钟、每个系统都露脸、可演示可讲清。
> 关联：docs/architecture.md（架构）、docs/progress.md（进度）。

## 1. 核心规则
- 2 名玩家，回合轮流制；20×20 程序化地图（边缘水域）；
- 单位：**战士**（Warrior，打架）、**移民**（Settler，建城）；开局各 1；
- 城市：demo 上限 **3 座/人**；生产 **战士 / 移民**；
- 城市结构：**中心单格 + 领地半径 2**（领地 = 距中心 ≤2 的格子，派生不存储）；产出为**统一固定值**（不做地块产出/市民工作）；建城间距规则 = 新城中心距任何已有城中心 >2（领地不重叠）；
- 玩家数据：PlayerState（Core，按玩家 Id 存个人状态）；城市上限 = GameRules.MaxCitiesPerPlayer（常量 3）；建城时校验（超出上限拒绝）；
- 科技：**单线 6 节点**，只解锁 1 个更强单位；
- 胜利：**征服唯一**——摧毁或占领对方所有城市；
- 对手：先做最简 AI（可单机演示），再接入联机（架构展示）。

## 2. 一局流程
开局：2 玩家对角出生，各 1 移民 + 1 战士。

每回合（玩家轮流）：
1. 操作阶段：
   - 战士：移动（耗移动力）；与相邻敌方单位/城市开战；
   - 移民：移动；在落点"建立城市"（消耗移民）；
   - 城市：切换生产项目（造战士 / 造移民）。
2. 结束回合；
3. 结算流水线（EndTurnPipeline）：
   - 每城 +生产力 → 攒够 → 城边生成单位；
   - 科技 +研究点（自动）；
   - 单位恢复移动力；
   - 胜负判定；
4. 轮到对手。

一局推进：前期建城 → 中期扩到 2~3 城 + 造兵 + 爬科技 → 后期攻城 → 终局判定。

## 3. 数值草案（占位，可调）
| 项 | 值 |
|---|---|
| 战士移动力 | 2 |
| 移民移动力 | 2 |
| 城市每回合生产力 | 5（基础，地形加成后加） |
| 造战士所需生产力 | 20 |
| 造移民所需生产力 | 30 |
| 科技节点数 | 6（单线） |
| 城市生命/攻击 | W4 战斗卡再定 |

## 4. 胜利 / 失败
- **胜**：对方所有城市被摧毁或占领（城防归零 → 城市易主）；
- **败**：自己的城市全部消失；
- 砍掉：首都规则、多种胜利、外交/贸易/宗教（不在 demo 范围）。

## 5. 战斗（W4 细化，先留位）
单位对单位/单位对城市：简化数值公式（攻击 - 防御 + 地形加成），先不做概率/随机波动以外的复杂度。

## 6. 与架构的对应
- 流程里的每个动作 = 一条命令：MoveOrder / FoundCityOrder / SetProductionOrder / EndTurnOrder / （W4）AttackOrder；
- 结算流水线 = EndTurnPipeline（生产系统 → 科技系统 → 单位重置 → 胜负判定）；
- AI（W4）= 一个自动产生命令的输入源——验证"命令 → Core"架构。
